# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Documentation Context (Non-Obvious)

- **No README** — There is no README.md. The only project-level documentation is this AGENTS.md and the inline CI workflow comments (in Spanish).
- **Two separate runtime images** — `Dockerfile` uses Eclipse Temurin 22 JDK as both build and runtime stage, but `pom.xml` declares `java.version=17`. The compiled bytecode targets Java 17, but the container runs on JDK 22.
- **Wallet directory name encodes the DB** — `Wallet_N72BZHZWYZGTE7OH/` is the Oracle Autonomous Database wallet specific to this deployment. The name is generated by Oracle Cloud and ties to that specific DB instance.
- **Config Server is optional in practice** — `spring.cloud.config.fail-fast=false` means the app runs without a Config Server; all effective config comes from `application.properties`. The Cloud Config dependency is present but not actively serving any properties in this repo.
- **JaCoCo is silently active** — Coverage is instrumented and reported on every `mvn test` run (report at `target/site/jacoco/index.html`), but there are no enforced coverage thresholds.
- **docker-compose hardcodes credentials** — `docker-compose.yml` contains real-looking DB credentials (`java_bd` / `ClaseFullStack1-`) as environment variables. These may be test/development credentials; production uses CI secrets.
